# Руководство пользователя

## Запуск

Откройте `index.html` в современном браузере. Установка, регистрация и подключение к интернету для работы планировщика не нужны.

## Добавление задачи

1. В блоке «Добавить задачу» введите название.
2. При желании укажите предмет и срок.
3. Выберите приоритет и нажмите «Добавить задачу».

Название обязательно. Предмет и срок можно не заполнять.

## Изменение списка

- Отметьте флажок на карточке, чтобы завершить задачу. Снимите отметку, чтобы вернуть её в работу.
- Нажмите значок карандаша, чтобы изменить название и предмет.
- Нажмите крестик, чтобы удалить задачу.
- В поле поиска введите часть названия или предмета.
- Кнопками «Все», «В работе» и «Готово» выберите нужные задачи.
- В меню «Сортировка» задайте порядок по сроку, приоритету или времени создания.

Счётчики в верхней части страницы показывают общее количество задач, количество незавершённых задач и количество выполненных.

## Справка в приложении

Кнопка «Справка» в верхней панели открывает краткие инструкции по основным действиям. Окно справки можно закрыть крестиком или клавишей Esc.

## Где хранятся данные

Список сохраняется в локальном хранилище текущего браузера на этом устройстве. Он не отправляется на сервер и автоматически не переносится на другие устройства. Очистка данных сайта или профиля браузера может удалить список задач.

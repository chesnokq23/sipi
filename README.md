# Учебный планер

Открой `index.html` в браузере или открой эту папку в VS Code. Проект работает без сборки и внешних библиотек.

## Возможности
- добавление задачи с предметом, сроком и приоритетом;
- отметка выполнения, возврат в работу, изменение названия/предмета и удаление;
- фильтр по статусу, поиск, сортировка;
- сводные счётчики и сохранение в localStorage.
- встроенная справка по использованию планера.

Данные хранятся только в браузере на текущем устройстве. Очистка данных браузера удалит список.

## Файлы
- `index.html` — структура страницы;
- `style.css` — адаптивное оформление;
- `script.js` — логика планировщика;
- `docs/Практические работы 1–4 — Учебный планер.docx` — отчёт по первому блоку;
- `docs/Практические работы 5–8 — Учебный планер.docx` — структурная и процессная модели, DFD, логическая модель данных, архитектура и матрица требований;
- `docs/Техническое задание — Учебный планер по ГОСТ 19.201-78.docx` — отдельное техническое задание;
- `docs/Руководство пользователя.md` — подробные инструкции;
- `docs/api/` и `docs/api-docs.zip` — API-документация, сгенерированная JSDoc;
- `docs/figures/` — схемы, включённые в отчёт по практикам 5–8.

## Генерация документации разработчика

Для работы сайта Node.js не нужен. Чтобы пересобрать API-документацию, установи dev-зависимость и запусти генератор:

```sh
npm install
npm run docs:api
```
